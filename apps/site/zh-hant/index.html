Features

功能概覽

查日期、看安排，也記下每天值得留住的小事。

農曆與節氣

農曆與二十四節氣在本機計算。全新植物線描圖示採用三種柔和顏色，Mac 使用小圖示，瀏覽器詳情展示精細大圖示；圖示隨農曆開關顯示。

系統日曆同步

直接查看 Mac 日曆中已有的行程，不會修改原有安排。有行程的日期會顯示彩色圓點，選取日期即可查看當天安排和視訊會議連結。

節假日與調休

訂閱中國大陸、中國香港和泰國節假日，也可新增自己的 iCal 日曆。大陸調休補班日明確標註「班」，關閉農曆仍可查看；各訂閱可設定獨立顏色。

月相

查看任意日期的月相。Luna 中今天的圓形背景隨月相變化，淺色模式採用溫暖的淡黃色。還可探索 3D 月球，位置僅在本機用於計算，從不上傳。

日記與待辦

macOS 應用程式支援每日自由文字日記；輸入 [] 買牛奶（或 [ ] / [x]）建立附核取方塊的待辦，完成後自動劃掉，可匯出 JSON。

標記與日記

瀏覽器擴充功能可為單日新增彩色標記與日記內容。

選單列與語言

選單列項可自訂：月相圖示、日期徽章、日號、農曆日、星期、時間，順序可調。介面語言：繁體中文、簡體中文、English、ไทย（泰語顯示佛曆）。
