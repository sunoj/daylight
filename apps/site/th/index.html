v2.0.3 · macOS 13+

แอปแถบเมนู macOS

คลิกไอคอนบนแถบเมนูเพื่อดูวันที่และกิจกรรมที่กำลังจะมาถึง ดูปฏิทินที่ใช้อยู่บน Mac เช่น iCloud, Google และ Exchange แล้วคลิกกิจกรรมเพื่อเปิดในแอปปฏิทิน

  • เลือก Luna เพื่อดูแผนประจำวัน หรือ Sol สำหรับปฏิทินที่กว้างขึ้น
  • สมัครปฏิทินวันหยุดหรือเพิ่มลิงก์ปฏิทินของคุณเอง
  • ดวงจันทร์ 3D ตำแหน่งอยู่ในเครื่องเท่านั้น
  • ไดอารี่พร้อมรายการสิ่งที่ต้องทำ พิมพ์ [] ซื้อนม เพื่อสร้างช่องทำเครื่องหมาย ส่งออก JSON ได้
  • ปรับแถบสถานะได้ เปิดเมื่อเข้าสู่ระบบ
  • รุ่นดาวน์โหลดจากเว็บไซต์รองรับการอัปเดตอัตโนมัติ

Luna · ค่าเริ่มต้น

ดูแผนวันนี้ได้ในพริบตา

เปิดปฏิทินขนาดกะทัดรัดได้ทุกเมื่อ เลือกวันเพื่อดูกิจกรรม บันทึก และรายการสิ่งที่ต้องทำ พร้อมข้างขึ้นข้างแรม จุดสีช่วยให้เห็นวันที่มีนัดหมายได้ง่าย

Sol

พื้นที่มากขึ้น ดูวันที่ได้สะดวก

ดูปฏิทินที่กว้างขึ้น พร้อมวันที่จันทรคติ ฤดูกาลจีน และเลขสัปดาห์ ดูข้างขึ้นข้างแรมหรือจดบันทึกของแต่ละวัน คลิกหัวข้อเพื่อข้ามไปยังเดือนหรือปีอื่น

Features

ฟีเจอร์โดยรวม

ดูวันที่ วางแผน และจดเรื่องเล็ก ๆ ที่อยากเก็บไว้

ปฏิทินจันทรคติและ 24 ฤดูกาลจีน

คำนวณปฏิทินจันทรคติและ 24 ฤดูกาลจีนในเครื่อง ไอคอนลายเส้นพฤกษศาสตร์ใหม่ใช้สามสีอ่อน มีแบบเล็กบน Mac และแบบละเอียดในเบราว์เซอร์ โดยแสดงเมื่อเปิดวันที่จันทรคติ

ปฏิทินระบบ

ดูกิจกรรมจากปฏิทินบน Mac โดยไม่เปลี่ยนแปลงข้อมูลเดิม จุดสีบอกวันที่มีกิจกรรม เลือกวันที่เพื่อดูตารางนัดหมายและลิงก์ประชุมวิดีโอ

วันหยุด

สมัครปฏิทินวันหยุดจีนแผ่นดินใหญ่ ฮ่องกง และไทย หรือเพิ่ม iCal ของคุณเอง วันทำงานชดเชยในจีนแสดงเครื่องหมายแยก แม้ปิดวันที่จันทรคติ แต่ละปฏิทินตั้งสีได้

ดวงจันทร์

ดูข้างขึ้นข้างแรมของทุกวันที่เลือก วงกลมวันนี้ใน Luna เปลี่ยนตามดวงจันทร์ พร้อมสีเหลืองอ่อนในโหมดสว่าง มีดวงจันทร์ 3D ที่ใช้ตำแหน่งคำนวณในเครื่องโดยไม่อัปโหลด

ไดอารี่และรายการสิ่งที่ต้องทำ

แอป macOS รองรับไดอารี่ข้อความอิสระรายวัน พิมพ์ [] ซื้อนม (หรือ [ ] / [x]) เพื่อสร้างรายการพร้อมช่องทำเครื่องหมาย — รายการที่เสร็จจะขีดฆ่า ส่งออก JSON ได้

เครื่องหมายและไดอารี่

ส่วนขยายเบราว์เซอร์เพิ่มเครื่องหมายสีและบันทึกไดอารี่ในแต่ละวัน

แถบสถานะและภาษา

ปรับรายการแถบสถานะได้: ไอคอนจันทร์ ป้ายวันที่ วันที่ วันจันทรคติ วันในสัปดาห์ เวลา จัดลำดับได้ ภาษาหน้าจอ: 中文, English, ไทย (ไทยแสดงปีพุทธศักราช)
