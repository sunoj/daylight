v2.0.3 · macOS 13+

macOS 菜单栏客户端

点击菜单栏图标，就能查看日期和接下来的安排。支持查看 Mac 日历中已有的 iCloud、Google、Exchange 等日程，点击即可在系统日历中打开。

  • 两种布局：Luna 方便查看当天安排，Sol 提供更宽敞的日历
  • 订阅节假日日历，也可添加自己的日历链接
  • 3D 月相模型，位置仅在本机使用
  • 日记与待办：输入 [] 买牛奶 生成可勾选待办，支持导出 JSON
  • 可自定义菜单栏显示项，支持登录时启动
  • 官网下载版支持自动更新

Features

功能概览

查日期、看安排，也记下每天值得留住的小事。

农历与节气

农历与二十四节气在设备本地计算。全新植物线描图标采用三种柔和颜色，Mac 使用小图标，浏览器详情展示精细大图标；图标随农历开关显示。

系统日历同步

直接查看 Mac 日历中已有的日程，不会修改原有安排。有日程的日期会显示彩色圆点，选中日期即可查看当天安排和视频会议链接。

节假日与调休

订阅中国大陆、中国香港和泰国节假日，也可添加自己的 iCal 日历。大陆调休补班日明确标注「班」，关闭农历仍可查看；各订阅可设置独立颜色。

月相

查看任意日期的月相。Luna 中今天的圆形背景随月相变化，浅色模式采用温暖的淡黄色。还可探索 3D 月球，位置仅在本机用于计算，从不上传。

日记与待办

macOS 客户端支持每日自由文本日记；输入 [] 买牛奶（或 [ ] / [x]）生成带复选框的待办，完成后自动划掉，可导出 JSON。

标记与日记

浏览器扩展可为单日添加彩色标记与日记内容。

菜单栏与语言

菜单栏项可自定义：月相图标、日期徽章、日号、农历日、星期、时间，顺序可调。界面语言：简体中文、繁體中文、English、ไทย（泰语显示佛历）。
